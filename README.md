# Hotel Chambord

Site vitrine responsive fictif pour l'Hotel Chambord, realise dans le cadre de l'Atelier de Professionnalisation 3 du BTS SIO.

## Auteur

**NASRULLA WALEED**

## Presentation

Le site presente les services d'un hotel-chateau : hebergement, restaurant, spa, activites, avis et contact. Il contient egalement des interfaces de reservation, connexion, inscription, recrutement et gestion administrative preparees pour une future integration backend.

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome

## Fonctionnalites

- Navigation responsive adaptee aux ecrans mobiles et desktop
- Pages de presentation des chambres, du restaurant, du spa et des activites
- Formulaires de contact, reservation, connexion et inscription
- Espace de demonstration pour la gestion des utilisateurs, du restaurant et du recrutement
- Page 404 personnalisee

## Lancer le projet

1. Clonez le depot :

```bash
git clone https://github.com/NWaleed786/Projet3-ChambordHotel.git
```

2. Ouvrez le fichier `index.html` dans un navigateur, ou utilisez l'extension Live Server dans Visual Studio Code.

## Structure

```text
.
|- index.html        # Page d'accueil
|- pages/            # Pages du site et interfaces de gestion
|- css/              # Feuilles de style
|- js/               # Scripts JavaScript
`- img/              # Images et logos
```

## Note

Ce projet est une demonstration frontend. Les formulaires et les espaces de gestion ne sont pas relies a une base de donnees ni a un serveur backend.
